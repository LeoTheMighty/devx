## Findings

Rows E1–E10 in `LEARN.md § epic-harness-fold-in (2026-07-26)`; the
narrative version:

1. **The loop merge tail broke the dvx103 discipline contract on first
   contact** (E1). Every loop-shipped spec landed without a `phase 4:`
   line, redding main's discipline test on the next branch cut. hfi104's
   iteration-1 learning *predicted the recurrence* before the fix
   existed; debug-cf65aa closed it structurally mid-epic.
2. **Verification parking abandoned a done item** (E2). hfi102's workers
   fired the ~7-min full suite and reported before observing it —
   iterations 6–8 each re-ran the same self-review while "suite still in
   flight," exhausting the budget. The revival found all 5 ACs done and
   the suite green. PR #82's iteration contract (never end with
   verification outstanding) is the corrective.
3. **Infra failures were charged to the item** (E3). Three hung worker
   sessions (~32 output tokens total, machine asleep, 60-min ceiling
   kills) counted as 3 item strikes; hfi103 was abandoned into `blocked`
   with a dead owner and DEV.md drift, wedging the backlog. PR #84's
   `infra-error` class (abort the *run*, not the item) is the corrective.
4. **The iteration budget can't tell verification tail from stall** (E4).
   hfi102 spent 5 iterations implementing and 3 re-verifying, then was
   abandoned as "8 iterations without acs_met" while effectively done.
   Partially addressed by #82; watch for budget-exhausted-while-done
   recurring.
5. **Abandon-preserves-work paid for itself twice** (E5). hfi102's
   revival was merge-main + suite + PR — zero rework. hfi103's preserved
   worktree held only bookkeeping and was discarded in one look. The
   morning-review "claims, not verdicts" discipline read both correctly.
6. **Red main is a multiplier on unattended confusion** (E7). The
   hfi101-induced discipline red sat on main for ~a day; four separate
   hfi102 iterations had to re-learn "that failure is baseline," and
   hfi104 fixed it opportunistically inside an unrelated item. Filed:
   loop preflight main-health check (`dev/dev-lpf101-2026-07-26T15:57-loop-preflight-main-health.md`).
7. **Loop token accounting is implausible** (E9). The productive 1h50m
   run self-reported ~11.5k in / ~9.3k out for 13 iterations producing
   +2,861 diff lines; real worker sessions are orders of magnitude
   larger. The 2M/item + 10M/run budgets can never trip on these
   numbers — unattended safety rails that don't measure aren't rails.
   Filed: `debug/debug-494590-2026-07-26T15:57-loop-token-accounting.md`.
8. **The harness permission gate did NOT fire for a detached loop
   worker writing `.claude/commands/`** (E8) — refines the
   `project_skill_perms_block_subagents` memory (observed gate applies
   to interactive/subagent contexts; the detached `claude` spawn wrote a
   skill file unattended). Memory updated; watch whether this is
   version-dependent.
9. **Cross-epic promotion: the unattended-frame class crossed the
   rich-2-retro bar** (v2-migration E2's pending-concordance + this
   epic's E1/E2/E3). Promoted to
   `LEARN.md § Cross-epic patterns` — "attended-era contracts break on
   first unattended contact"; re-review inherited primitives under the
   nobody-is-watching frame and treat first unattended runs as a
   verification stage with post-run reconciliation.
